# Consumer Consent for Plaid Data Collection, Processing, and Storage

**Company:** Cashpile  
**Effective Date:** April 26, 2026  
**Version:** 1.0

---

## 1. Purpose

This document describes how Cashpile obtains consumer consent for the collection, processing, and storage of financial data accessed through Plaid.

---

## 2. Consent Model

Cashpile obtains consumer consent through the user’s voluntary decision to connect a financial account using Plaid Link and through Cashpile’s application terms, disclosures, and privacy policy.

Under this model:

- The user must be authenticated into Cashpile before starting the connection flow
- The user affirmatively chooses to launch Plaid Link
- The user selects a financial institution and authorizes access through Plaid
- The user consents to Cashpile receiving and processing authorized account and transaction data in order to provide requested product functionality

---

## 3. Scope of Consent

When a user connects a financial account, the user authorizes Cashpile to collect, process, store, and use data made available through Plaid for the following purposes:

- Linking financial accounts to the Cashpile application
- Importing transaction and balance data
- Displaying financial account information within the application
- Supporting bookkeeping, reporting, categorization, and related product features
- Maintaining ongoing synchronization for connected accounts
- Securing and troubleshooting the service

Cashpile uses the data only for purposes consistent with the user’s authorization and Cashpile’s Privacy Policy.

---

## 4. Types of Data Covered by Consent

The consent applies to financial information made available through Plaid, which may include:

- Financial institution name
- Account identifiers and masked account details
- Account balances
- Transaction history
- Other financial data the user authorizes through the Plaid connection

Cashpile does not ask for or store the user’s bank login credentials directly.

---

## 5. User Acknowledgment

By proceeding through Plaid Link and connecting an account, the user acknowledges that:

- The user is authorizing Cashpile to access financial data through Plaid
- Cashpile may store and process the data to provide the application’s features
- The data may continue to sync until the user disconnects the account or deletes the Cashpile account
- Cashpile’s Privacy Policy and retention practices apply to the collected data

---

## 6. Withdrawal of Consent

Users may withdraw consent by:

- Disconnecting linked financial accounts
- Requesting deletion of their Cashpile account
- Contacting Cashpile to request data deletion, subject to legal and operational retention obligations

Withdrawal of consent does not require Cashpile to delete data that must be retained for legal, tax, accounting, security, fraud-prevention, or dispute-resolution purposes.
